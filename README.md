# Molscrub Viewer

Experimental GUI for Molscrub built in React + Electron. Molscrub runs as a python server in the background while the electron app constitutes the frontend gui. 

Requires: 

- Python
- FastAPI (for the backend server)
- Molscrub 
- node and npm 


To run: 

```bash
git clone https://github.com/joanimato/molscrub_viewer.git # clone the repo
cd molscrub_viewer
npm install # install dependencies
npm run start
```
